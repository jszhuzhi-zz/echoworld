# EchoWorld v1.5 Stable

**人机共玩的超级大富翁 — 一起来赚钱！**

一个自进化的无限世界模拟游戏。AI 智能体与人类玩家共存于商业规则之中，掷骰子探索无限地图，建造设施、消费恢复、金融投资，在马斯洛需求层次的建筑体系中求生致富。

---

## 游戏简介

EchoWorld 是一款 3D 网页端大富翁式生存经营游戏。你将进入一个**无限延伸**的程序化生成世界，通过掷骰子在道路上移动，路过各类格子触发事件：缴税、领福利、遭遇随机事件。你需要管理三项生命指标（饱食度、体力、幸福感），在路边建造设施赚取消费收入，利用银行系统存贷款增值财富，与其他玩家进行建筑交易——一切的目标只有一个：**活下去，变更富**。

### 核心特色

- **无限世界** — 地图以区块懒加载方式无限延伸，永远有新的领地等你探索
- **马斯洛建筑体系** — 15 种建筑跨越 5 层需求层次，从小食摊到创业中心
- **真实时间经济** — 体力每小时恢复、饥饿每小时消耗，与现实时间同步
- **人机共存** — AI 智能体拥有独立性格和 LLM 驱动的决策能力
- **永久死亡** — 饥饿或幸福感归零即永久死亡，财富充公，紧张刺激
- **自进化规则** — 税率、收入、福利等参数根据世界经济数据自动调整

## 玩法指南

### 1. 掷骰子 & 移动

点击 🎲 骰子按钮掷出 1~6 步。系统自动沿道路前进，遇到岔路口时选择方向（顺时针 ↻ 或逆时针 ↺）。每次移动消耗 **5 点体力**，每天有 **20 次行动上限**（可用健康值兑换额外行动）。

### 2. 格子事件

| 格子类型 | 图标 | 效果 |
|---------|------|------|
| 起点 | 🏠 | 玩家出生点 |
| 税务 | 💸 | 缴纳当前资产 5% 的税金 |
| 福利 | 🎁 | 获得 100 CC + 饱食度 +10 + 体力 +5 |
| 事件 | ❓ | 50% 幸运获得 50~350 CC / 50% 损失 20~170 CC |
| 道路 | — | 可建造设施的空地 |
| 交叉路口 | — | 岔路选择点，旁边生成建筑地块 |

### 3. 生命三要素

| 指标 | 图标 | 消耗 | 恢复 | 归零后果 |
|------|------|------|------|---------|
| **饱食度** | 🍔 | 每真实小时 -1 | 食物类建筑消费 / 80 CC 紧急恢复 +20 | **永久死亡** |
| **体力** | ⚡ | 每次移动 -5 | 每真实小时 +5 / 住宿类建筑 / 100 CC 紧急恢复 +25 | 无法行动（不死亡） |
| **幸福感** | 😊 | 每 2 真实小时 -1 / 每 10 步 -1 | 娱乐类建筑消费 | **永久死亡** |

点击顶部健康条可查看详细规则说明，并可直接用 CC 紧急恢复。

### 4. 建造 & 经营

在道路或交叉口空地上建造设施。其他玩家路过消费时，你将**收取使用费**。建筑随使用次数自动升级（最高 Lv.5），高等级建筑效果更强、收费更高。

### 5. 路过消费

移动途中经过他人建筑时，会弹出消费提示（8 秒倒计时）。选择消费可恢复生命指标，费用支付给建筑业主。**自己的建筑也可以消费**（费用自付自收，但享受效果）。

### 6. 银行系统

在储蓄所（🏧）或银行（🏦）可进行金融操作：

- **存款**：获得每日利息（默认 3%~5%）
- **贷款**：按信用额度借款（利息 5%~8%/日）
- **业主自定义利率**：银行建筑的业主可调整存贷利率

### 7. 建筑交易

可以将建筑挂牌出售，其他玩家出价购买。交易包含 **10% 交易税**，收入归世界国库。

## 经济系统

### 货币：CC（Commerce Coin）

- **初始资金**：注册即获 1,000 CC
- **邀请奖励**：被邀请人注册后，邀请者获 100 CC
- **充值汇率**：100 CC = 1 元人民币（支持微信/支付宝）
- **首充赠送**：首次充值额外赠送 50%

### 资金流转

```
玩家消费 ──→ 建筑业主（使用费收入）
       └──→ 世界国库（税务格子 / 交易税 / 死亡充公）
               └──→ 福利格子发放 / 财富再分配
```

### 自进化规则

世界每 7 个游戏日自动评估经济指标：

| 指标 | 条件 | 调整 |
|------|------|------|
| 基尼系数 | > 0.5 | 提高税率 |
| 平均财富 | < 1000 | 提高基础收入 |
| GDP 增长 | 下降 5% | 降低建筑衰减 |
| 破产率 | > 20% | 增加福利发放 |

## 技术架构

```
src/
├── core/              # 核心引擎（世界时钟、状态、事件总线）
├── entities/          # 实体系统（玩家/AI 角色）
├── economy/           # 经济系统（银行、税收）
├── infrastructure/    # 基础设施（建筑管理）
├── market/            # 市场系统（交易撮合、供需定价）
├── ai/                # AI 智能体（性格决策、LLM 接入）
├── rules/             # 规则引擎（自进化）
├── board/             # 无限世界（地图生成、移动逻辑）
├── api/               # HTTP API 服务（Express）
└── index.ts           # 入口文件

public/
├── index.html         # 首页（游戏介绍）
└── game.html          # 3D 游戏主界面（Three.js）
```

### 技术栈

| 层级 | 技术 |
|------|------|
| **后端** | Node.js + Express + TypeScript |
| **前端** | Three.js 3D 渲染 + 原生 HTML/CSS/JS |
| **认证** | JWT（7 天有效期）+ bcryptjs 密码加密 |
| **支付** | BufPay（微信/支付宝） |
| **AI** | 智谱 GLM-4-Flash / OpenAI / Anthropic |
| **数据** | JSON 文件持久化 |
| **国际化** | 中文/英文双语 |

### 代码量

| 文件 | 行数 |
|------|------|
| 后端 TypeScript（全部） | ~6,700 行 |
| 游戏前端 game.html | ~3,600 行 |
| **总计** | **~10,300 行** |

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式运行
npm run dev

# 编译
npm run build

# 生产模式运行
npm start
```
